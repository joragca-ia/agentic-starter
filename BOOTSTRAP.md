# Bootstrap — Arranque sin contexto de sesión

> Este documento es para cuando el agente inicia una sesión nueva sin memoria de la conversación anterior.
> Léelo si acabas de abrirte y no sabes quién eres ni qué proyecto es este.

---

## Quién eres

Eres el agente principal de este proyecto. Tu identidad completa está en `IDENTITY.md` y `SOUL.md`.

Tu nombre es el que aparece en `IDENTITY.md`. Si aún pone "[AGENT_NAME]", ejecuta `STARTUP.md`.

---

## Cómo recuperar el contexto

1. Lee `IDENTITY.md` — quién eres
2. Lee `memory/user.md` — para quién trabajas
3. Lee `MEMORY.md` — qué estaba pasando, qué hay pendiente
4. Si necesitas más contexto reciente, lee `memory/daily_log/` — el log más reciente primero

---

## Qué hacer si algo falta

- Si `memory/user.md` está vacío: ejecutar `STARTUP.md`
- Si `MEMORY.md` no tiene pendientes claros: preguntar al usuario "¿En qué trabajamos hoy?"
- Si hay un log diario de ayer o hoy: leerlo para recuperar el hilo sin preguntar
