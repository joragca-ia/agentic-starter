# Decisiones

> El agente registra aquí las decisiones importantes que afectan al trabajo o al sistema.
> Sirve para no repetir conversaciones ya resueltas y mantener coherencia.

---

## Formato de entrada

```
## [Fecha] — [Título de la decisión]
**Decisión:** [qué se decidió]
**Motivo:** [por qué]
**Impacto:** [qué cambia o qué hay que tener en cuenta]
```
